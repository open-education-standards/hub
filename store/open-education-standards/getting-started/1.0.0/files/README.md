# Getting started with OES

A short OES course: what OES is, how its specifications fit together, and
how to write your first question, with a self-check quiz. It is also a
complete, valid OES package, published on the
[OES hub](https://open-education-standards.github.io/hub/).

- Start at [`course.json`](./course.json).
- [`package.json`](./package.json) is the OPK manifest that makes this
  folder a package.
